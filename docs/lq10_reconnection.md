# LQ10 断电重连恢复

本次需更新各地面电脑和对应无人机的竞赛程序，再按 README 原命令启动。机队 IP、认证令牌、自定义机载启动指令保持原配置。无需修改厂商程序、目标检测程序或程序 B。

## 恢复行为

| 功能 | 断连期间 | 网络恢复后 |
| --- | --- | --- |
| 任务链路及遥测 | 双向心跳每秒一次，8 秒无有效应答即释放旧连接；机载发送有超时上限 | 机载自动重新握手，优先回传最新遥测；不会自动重发任务、起飞或返航命令 |
| 图片与同名 JSON | 先保存在机载磁盘；传输失败保留未确认文件 | 按 ACK 标记续传；本机成功返航或比赛23分30秒首次触发最终缺失清单，详见 [补传与上报规则](return_reporting.md)；同名文件不会重复落盘 |
| 图片任务计时 | 起飞时通知失败单独登记待恢复，即使尚无图片 | 重新发送携带原始开始时间的通知，恢复原计时，不创建新图片任务 |
| 飞行采集 | rosbag 在机载继续记录；停止、校验和导出作业不依附 SSH 会话 | 自动继续查询原作业和下载；不重复启动采集或导出；已完成且 SHA-256 一致的文件跳过，未完成的单个文件重新下载 |
| 程序状态及打印 | SSH 失败记录中文错误，不因此停止飞机上的程序 | 自动恢复读取原程序状态、增量日志；不自动重启人工停止的程序 |
| 返航 | 断连时发送失败会显示错误；写入 TCP 缓冲区不等于机载确认 | 可重新手动选择返航。上次请求未获得机载返航状态确认时允许再次发送；本工程和程序 B 仍使用原有返航处理及遥控器接管约束 |

心跳只判断链路，不会把旧的飞控、GPS 或目标数据刷新为新数据。恢复耗时包括 LQ10 建链和网卡恢复时间，不能以软件心跳间隔推断无线模块必定在几秒内恢复。

采集时若在失联状态点击停止，地面端会等待恢复后执行停止；等待期间机载可能继续记录。下载校验通过前保留机载原文件。SSH 密钥错误、磁盘故障和文件校验失败会明确报错，不作为普通断网无限重试。

## 验证与日志

已使用本机 TCP 丢包代理验证双向断流、上行单向断流、下行单向断流，验证重新握手、遥测恢复、人工返航以及不重放任务。图片测试覆盖半帧中断、ACK 丢失、缺失清单补传和无图片时的计时通知失败。采集测试覆盖 SSH 响应丢失、同一作业查询、文件下载重试与 SHA-256 校验。未通过本次测试连接真实飞机、执行飞行或给 LQ10 断电。

地面 `ground_logs/sessions/` 中的审计日志记录任务链路握手、断开和网络异常；程序窗口记录 SSH 恢复及程序状态；图片接收日志记录补传清单和保存结果；采集窗口记录断连、恢复、下载与校验。采集的机载作业日志另保存在对应 `flight_records/uavN_日期_时间/.ground_jobs/` 下。

本次修复只处理竞赛程序的连接恢复。若厂商 Prometheus 通信保护、遥控器或飞控在 LQ10 重连时触发降落，竞赛程序不会自动取消降落、解锁或重新取得控制权；该问题需要结合对应飞行日志单独定位。
