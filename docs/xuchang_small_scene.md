# 许昌试飞场地（小）固定方案

坐标基准为 WGS84 十进制度。下表按「纬度、经度」书写；机载外部程序 B 的航点话题仍按 `[经度, 纬度, 相对高度]` 发布。

| 点位 | 纬度 | 经度 |
| --- | ---: | ---: |
| 外边界点 1 | 34.136123 | 113.908559 |
| 外边界点 2 | 34.136278 | 113.912981 |
| 外边界点 3 | 34.140263 | 113.908491 |
| 外边界点 4 | 34.140655 | 113.912085 |
| 固定起飞点 | 34.138282 | 113.909077 |

四个外边界点按 1→2→4→3 围成多边形。为了测试返航绕行，方案在其内部设置了一个**规划用矩形扣除区**，该区不侦察、进场与返航路线不穿越。扣除区并非用户测绘的障碍物，实际试飞前需核对其位置和周边可飞条件。

| 扣除区角点 | 纬度 | 经度 |
| --- | ---: | ---: |
| 西南 | 34.137250 | 113.910250 |
| 东南 | 34.137250 | 113.911850 |
| 东北 | 34.139150 | 113.911850 |
| 西北 | 34.139150 | 113.910250 |

外边界面积约 175975 平方米，扣除区约 31103 平方米，剩余约 144872 平方米全部按侦察半径 75 米覆盖。航速 5 米/秒、每点扫描 10 秒，与大连场景一致。当前任务归属已交换 UAV1 与 UAV4 的原子区及航点：UAV2、3、4 的子区比 UAV1、5、6 距固定起飞点更远。高度仍按无人机编号选择，不随子区交换。侦察航点及连接航段、进场和返航路径距外边界、扣除区边界至少 5 米。实际起降 GPS 若处于不足 5 米的缓冲区或扣除区内，任务分派会拒绝该架飞机。

场景只选 GPS 坐标系，所有高度档都可选。新增「约 54 米」档：UAV1～6 分别为 **64、60、56、52、48、44 米**（相对起飞点高度）；该档在其他场景也可选。六机规划航点保存在 `competition_backend/competition_backend/xuchang_small_prepared.json`，进返场路线保存在 `competition_backend/competition_backend/external_transit_prepared.json`。运行时只读取和核验文件，赛前修改区域时按顺序运行 `tools/prepare_xuchang_small_plan.py`、`tools/prepare_transit_routes.py`、`tools/build_plans_3d.py`。
