# GitHub 协作说明

本仓库保存 competition_development 的源码、测试、ROS 包、配置模板和部署脚本。su17_experiment 作为外部 ROS 依赖，不包含在此仓库中。

## 首次使用

Windows 地面端在项目目录运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\install_ground_station.ps1` 安装后端依赖。

如需云台视频，将团队当前部署版本的 mediamtx.exe 复制到 third_party/mediamtx/。源码副本保留对应配置模板和 LICENSE；可执行文件和自动生成的证书不进入 Git。仅验证网页和点云时，启动脚本可使用 -DisableMediaMtx -DisableImageReceiver。

Ubuntu 机载/ROS 端按各 src 包的 README 构建和启动，加载已有 su17_experiment 环境时只读取该环境。

## 本地配置与提交

AuthToken、PeerToken 和 PointCloudIngestToken 由使用者在本机设置。文档中的 YOUR_AUTH_TOKEN 是占位符，实际令牌不要提交到 Git。

运行记录、点云、图片、虚拟环境、编译目录、私钥、证书和历史编辑备份已从共享副本排除。它们仍保留在原工作目录中。

更改前先拉取团队分支，开发使用独立分支，通过 GitHub 合并请求提交给同事审阅。
