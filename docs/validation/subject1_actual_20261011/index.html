持续整理测试使用六机目标、45点轨迹、后续静目标更新、损坏JSON和无效坐标，30次三线程并发重建，加10轮追加更新重建；每轮均生成可校验的16目标JSON、6个动目标及每动目标最早40点。既有低速转静态、10米/5米距离、轨迹相似、名额及质量排序规则均保留。

本次修复

  1. 图片复制被占用或失败时，继续整理目标JSON；错误写入日志及submission-format.json → image_copy_errors，后续重建重试图片，不用旧图片代替新定位记录。
