# 多地面端比赛计时

主界面“比赛已用时间”从任务发布者选择本地终端、进入程序开始累计，包含本机服务启动等待时间。刷新网页、关闭详情或返回首页不会重置；发布端后端重新启动并重新进入时建立新计时会话。

每个已进入的地面端都可点击“修改”，输入当前应显示的分钟和秒，点击“同步时间”。例如改为 3 分 20 秒，随后从 3 分 20 秒继续累计。无人机实时任务详情顶部仅显示，不提供修改入口。

各端修改由任务发布端串行确认，以发布端最后接收的修改为准；通过现有地面互联轮询同步（通常约 0.5 秒一个周期）。旧版本快照不能覆盖新修改。无需连接无人机，也无需先规划任务。

计时使用单调时钟，跨电脑传递已用时长，不依赖六台电脑系统时间完全一致。断网时按最后同步值继续计时并显示提示；恢复连接后同步。任务发布端不可达时，其他端不能确认新的时间修改，不会假报成功。

比赛计时独立于任务倒计时、起飞、返航、图片任务时间戳，不改变机载飞行任务；开始和修改会记录在原地面会话诊断日志。

需更新六台地面端并刷新网页；本次无需更新机载端，原部署与启动命令不变。
