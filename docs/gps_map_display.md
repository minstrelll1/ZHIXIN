# GPS 任务地图实际位置

GPS 规划图统一使用当前任务保存的 GPS 原点和投影系数：X 向北、Y 向西。实际位置、历史轨迹、速度箭头和详情数据使用同一转换。飞控本地 ENU 原始位置保留，不直接叠加在 GPS 任务图上。

竞赛机载程序只读订阅 `/uavN/mavros/global_position/global`，将有效、两秒内的 NavSatFix 经纬度以双精度放入 `gps_position` 遥测字段，供地图使用。不修改厂商消息、飞行控制、任务参考点或程序 B 的路径协议。

优先使用原始 MAVROS GPS；缺少该数据时可显示 Prometheus 经纬度并标注“低精度 GPS”。GPS 无效或遥测过期时不生成定位点，也不追加轨迹。XYZ 模式维持原有本地坐标显示。

本次修改需要更新地面代码并重新部署机载竞赛程序；沿用 `latest_deployment_activation.md` 的更新、部署与启动命令。重新启动后刷新网页。

历史 UAVState 的 float32 经纬精度不能从已有 CSV 恢复。当前飞行记录未包含原始 NavSatFix，因此历史回放只能验证坐标方向与基准，不能证明厘米级定位精度。原始经纬度保留更多位数也不保证传感器本身的定位准确度。
