独立 3D 预览使用说明

1. 双击 planning_preview.html 即可通过 file:// 打开。全部最终 JSON 已内嵌，无 CDN、外部字体、地图服务或网络请求；不需要启动服务器。不连接或发送任何飞行指令。
2. 左侧切换三个场景、六机和 upper/lower 层；拖动旋转，Shift+拖动平移，滚轮缩放；右上可切换俯视、恢复 3D、适应窗口和导出当前画布 PNG。
3. 默认 XY 与 Z 同为真实米制比例 1:1。选择高度放大后标题同步标明倍率。相对高度不是海拔；所有名义参考起点不代表六机真实开机 GPS。
4. 扫描圆默认放在各层高度平面以分辨两层，也可改为地面投影。圆盘只是水平覆盖半径的表达，不是相机视锥或高度决定覆盖半径的光学模型。上层路线实线，下层虚线；进返场虚线，层间白色点线。
5. 免扫、强禁扫和禁飞三类几何分别显示。完整保留所有多边形、洞和 MultiPolygon 分块。强禁扫针对完整扫描圆盘；覆盖豁免本身不等于禁飞。许昌禁飞区额外以虚线空间轮廓显示，轮廓显示高度仅作识别，不是允许越顶的高度界限。
6. 底部播放严格读取 segments 的完整顺序和开始/结束时间；无额外拟造飞行动作。当前扫描点、层、遍数随时间显示。A 的转折点两个连续扫描各有独立时间段。六机均独立从 t=0 起算，动画不是已经验证的动态避碰计划。
7. 全场覆盖率来自最终 JSON 的 scene_metrics，筛选无人机不会改变全场分母；每机表格显示本机子区的覆盖率。悬停航点可查看 WGS84 纬度/经度、北/西坐标、高度、半径、遍数及编号。橙色未覆盖图层依据每机每层未覆盖几何，可能因层间或跨区圆盘覆盖而与全场未覆盖几何不同。
8. 从最终 JSON 重新生成：python3 build_preview.py。只用 Python 3 标准库。
9. 可选浏览器回归检查：安装适合本机操作系统的 Node.js、Playwright 及其 Chromium 后运行 node preview_browser_check.cjs。可用 NODE_PATH 指定外部安装位置。本次测试环境是 Playwright 1.48.2 / Chromium 130.0.6723.31，浏览器上下文显式设为 offline:true，并以 file:// 打开最终 HTML。
10. preview_validation_report.json 保存浏览器检查结果、最终 JSON 与 HTML 的 SHA256、零外部请求/零 JS 错误记录；preview_evidence/ 保存三个场景的 3D 视图与地面投影俯视图。浏览器测试只验证展示及交互；几何和时间硬约束以独立 validate_plan.py 的复算报告为准。

实现说明：使用 Canvas 2D 实现三维正投影，无第三方运行库；XY/Z 经过同一旋转与统一米制缩放，再执行视角投影。图中圆盘采用 64 边显示近似，最终覆盖指标仍直接读取规划结果中严格复算的高精度圆盘数据，不能从截图反算覆盖面积。
